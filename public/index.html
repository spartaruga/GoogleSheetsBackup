Configurazione guidata

Fai questi passaggi una volta per ogni PC.

1

Controlla il PC

L’installer include tutti i componenti. Non devi installare Node.js.

Controllo Node.js…
2

Crea il progetto Google Cloud

  1. Apri Google Cloud e crea o seleziona un progetto.
  2. Abilita Google Sheets API, Google Drive API e Apps Script API.
  3. In Google Auth Platform → Branding/Audience configura l'app OAuth.
Crea progetto Sheets API Drive API Apps Script API Configura OAuth
3

Crea le credenziali Desktop

  1. Apri Google Auth Platform → Clients.
  2. Premi Create client e scegli Desktop app.
  3. Scarica il JSON e selezionalo qui sotto.
Apri Clients
Credenziali non configurate
4

Abilita l'accesso agli script

Nelle impostazioni personali di Apps Script attiva API Google Apps Script. Ogni utilizzatore deve farlo sul proprio account.

Apri impostazioni Apps Script
5

Collega il tuo account Google

Si apre Google nel browser. Usa un account che possa leggere i Fogli e gli Apps Script autorizzati.

Account non collegato

Il primo collegamento richiede sola lettura. Per scrivere usa “Abilita pubblicazione” nella sezione Modifiche AI. I permessi già concessi alle vecchie versioni restano validi.

Uso da parte di più persone

Stessa azienda Google Workspace: imposta l'audience OAuth su Internal. Distribuisci questo programma e il JSON Desktop separatamente. Ogni persona importa il JSON e accede col proprio account.

Account esterni: usa audience External. Durante i test aggiungi gli indirizzi come test user; per uso stabile pubblica l'app secondo le richieste mostrate da Google.

Ogni account deve avere accesso ai Fogli e agli script. I token personali restano sul singolo PC e non finiscono nei backup.

Modifiche ricevute dall'AI

Carica il file modifiche-ai.json prodotto seguendo le istruzioni contenute nello ZIP.

1. Carica e controlla

Solo se vuoi aggiornare Google: autorizza la scrittura usando lo stesso account. Non viene pubblicato nulla con questo pulsante.

Il programma verifica progetto, versione di partenza, hash e file intoccabili.

Puoi creare solo la copia locale oppure pubblicarla direttamente su Google. Prima di pubblicare viene creato un backup di sicurezza e viene verificato che Apps Script non sia cambiato dopo il backup usato dall'AI.

2. Anteprima operazioni
