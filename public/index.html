Uso da parte di più persone

Stessa azienda Google Workspace: imposta l'audience OAuth su Internal. Distribuisci questo programma e il JSON Desktop separatamente. Ogni persona importa il JSON e accede col proprio account.

Account esterni: usa audience External. Durante i test aggiungi gli indirizzi come test user; per uso stabile pubblica l'app secondo le richieste mostrate da Google.

Ogni account deve avere accesso ai Fogli e agli script. I token personali restano sul singolo PC e non finiscono nei backup.

Se lasci vuoto lo Script ID, il programma salva solo il Foglio. Se lasci vuoto il Foglio, salva solo Apps Script.

Esegui backup

Vengono elaborati tutti i progetti segnati come attivi.

Destinazione

Usa gli ID già salvati. I dettagli Cloud seguono le impostazioni del progetto qui sotto. I trigger sono la copia dell’ultimo inventario salvato, con la sua data. Le scelte restano memorizzate. Per le esecuzioni abilita la diagnostica una volta. I token riconoscibili nei log vengono censurati nella copia ZIP per l’AI.

Controllo segreti obbligatorio

Prima del backup il programma analizza tutti gli script. Potrai censurare token, escludere file e renderli intoccabili.

Log

Pronto.
Impostazioni esecuzioni e trigger

Imposta i dettagli del progetto una volta. I dati selezionati vengono raccolti con il backup nello stesso ZIP.

L’API restituisce stato e durata. I dettagli degli errori richiedono Cloud Logging API abilitata, un progetto Cloud standard dello script e permessi di lettura dei log. I file possono contenere dati personali o segreti scritti nei log: controllali prima di condividerli.

Inventario trigger salvato

Esegui gwbExportTriggers in Apps Script e salva qui il JSON del log una volta. Verrà riutilizzato nei successivi ZIP; dopo una modifica dei trigger aggiorna l’inventario. Gli orari dei trigger creati da altri installer non sono esposti da Google.
